Introdução ao HTML

Neste primeiro módulo, você vai entender o que é HTML, como ele surgiu, como funciona a web e quais ferramentas você precisa para começar a programar.

📖 O que é HTML?

HTML significa HyperText Markup Language (Linguagem de Marcação de Hipertexto, em português). Não se assuste com o nome complicado — HTML é mais simples do que parece!

Imagine que você está escrevendo um documento no Word. Você usa negrito, itálico, títulos, listas... O HTML faz a mesma coisa, mas para páginas da internet. Ele diz ao navegador (Chrome, Firefox, Edge) como exibir o conteúdo.

HTML não é uma linguagem de programação — é uma linguagem de marcação. Isso significa que você não "programa" lógica ou cálculos. Você apenas marca o conteúdo para que o navegador saiba o que é um título, o que é um parágrafo, o que é uma imagem, e assim por diante.

💡
Pense assim:
Se a web fosse uma casa, o HTML seria a estrutura (paredes, portas, janelas). O CSS seria a pintura e decoração. E o JavaScript seria a eletricidade e os aparelhos que fazem coisas acontecerem.

📜 Um Pouco de História

O HTML foi criado em 1991 por Tim Berners-Lee, um cientista britânico que trabalhava no CERN (organização europeia de pesquisa nuclear). Ele queria uma forma de compartilhar documentos entre pesquisadores de diferentes lugares do mundo.

Desde então, o HTML evoluiu muito:

Versão Ano Principais novidades
HTML 1.0 1991 A primeira versão, com tags básicas como títulos, parágrafos e links
HTML 4.01 1999 Tabelas, formulários, frames e folhas de estilo
XHTML 2000 HTML escrito com regras mais rígidas do XML
HTML5 2014 Vídeo, áudio, canvas, tags semânticas, geolocalização
🎯
Hoje usamos HTML5
A versão atual e mais utilizada é o HTML5. É ele que vamos aprender neste curso. O HTML5 trouxe muitas melhorias, especialmente tags semânticas que deixam o código mais organizado e acessível.

🌐 Como Funciona a Web?

Para entender o HTML, é importante saber como uma página da web chega até você. O processo é mais simples do que parece:

💻 Você digita
o endereço
→
📡 Requisição vai
para a internet
→
🖥️ Servidor recebe
e processa
→
📄 Servidor envia
o arquivo HTML
→
🔍 Navegador lê
e exibe a página

Quando você acessa um site, seu navegador (Chrome, Firefox, etc.) faz uma requisição para um servidor. O servidor responde enviando arquivos — geralmente HTML, CSS e JavaScript. O navegador lê esses arquivos e monta a página que você vê na tela.

O HTML é sempre o primeiro arquivo que o navegador recebe. É ele que diz: "Ei, aqui tem um título, aqui tem um parágrafo, aqui tem uma imagem..."

🛠️ Ferramentas que Você Precisa

A boa notícia é que você precisa de muito pouco para começar:

📝

Editor de Código

Recomendamos o VS Code (gratuito). Outras opções: Sublime Text, Atom, Notepad++.

🔍

Navegador

Qualquer um serve: Chrome, Firefox, Edge, Safari. Use o que você já tem instalado.

💪

Vontade de Aprender

Isso é o mais importante! Não precisa saber nada de programação para começar.

⚠️
Não use Word ou bloco de notas comum!
Editores de código como o VS Code ajudam com syntax highlighting (colorir o código), autocompletar e indentação automática. Isso faz uma enorme diferença na hora de programar.

👋 Seu Primeiro Código: Hello World

A tradição na programação é começar com um "Hello World" — um programa simples que exibe essa mensagem. Vamos fazer isso em HTML!

📄 index.html Copie este código 
<!DOCTYPE html>
<html>
  <head>
    <title>Minha Primeira Página</title>
  </head>
  <body>
    <h1>Hello World!</h1>
    <p>Estou aprendendo HTML!</p>
  </body>
</html>
👁️ Resultado no navegador

Hello World!

Estou aprendendo HTML!

Não se preocupe se não entendeu tudo ainda. Nos próximos módulos vamos explicar cada parte dessa estrutura em detalhes. O importante agora é ver que HTML é apenas texto com tags!

🎯 Exercício Prático

Crie sua Primeira Página

Agora é sua vez! Siga os passos abaixo para criar sua primeira página HTML do zero.

📋 Instruções:
  • Abra o VS Code (ou seu editor de código)
  • Crie um novo arquivo chamado index.html
  • Copie o código "Hello World" acima
  • Salve o arquivo (Ctrl+S ou Cmd+S)
  • Clique duas vezes no arquivo para abrir no navegador
  • Veja o resultado na tela! 🎉
🎨
Desafio extra:
Tente alterar o texto "Hello World!" para o seu nome. Depois, mude o texto do parágrafo para uma frase sobre você. Salve e atualize o navegador (F5) para ver as mudanças!
