Links e Navegação

Aprenda a conectar páginas com links, entender caminhos absolutos e relativos, criar âncoras, links de email e telefone e montar um menu de navegação.

🔗 A tag <a> e o atributo href

O que faz a web ser uma teia (web, em inglês) é justamente a possibilidade de ir de uma página para outra clicando. Isso é feito com os links (ou hiperlinks), e a tag responsável por eles é a <a>, de anchor (âncora).

Vamos por partes. Veja o link mais simples possível:

📄 Seu primeiro link 
<a href="https://www.wikipedia.org">Visitar a Wikipédia</a>

Esse código tem quatro peças. Vamos identificar cada uma:

1. <a ...> é a tag de abertura: ela avisa ao navegador "aqui começa um link".
2. href="..." é um atributo. O nome href vem de hypertext reference e guarda para onde o link leva. O endereço vai sempre entre aspas.
3. Visitar a Wikipédia é o texto do link: a parte que a pessoa vê e clica.
4. </a> é a tag de fechamento, que encerra o link. Se você esquecer dela, todo o texto seguinte vira link!

👁️ Resultado

Visitar a Wikipédia

💡
Atributos: o padrão nome="valor"
Os atributos dão informações extras a uma tag e sempre ficam dentro da tag de abertura, nunca na de fechamento. O padrão é nome="valor". Você já viu isso no módulo 2 com lang="pt-BR" no <html>. Agora vai usar muito o href.

🗺️ Links externos e links internos (caminhos)

O valor do href pode ser de dois tipos, e entender a diferença é uma das coisas mais importantes de todo o curso:

Link absoluto (externo): o endereço completo, começando com https://. Serve para levar a outros sites.
Link relativo (interno): só o caminho até outro arquivo do seu próprio site. Funciona como dar direções a partir de onde você está.

📄 Absoluto e relativos 
<!-- Absoluto: outro site -->
<a href="https://developer.mozilla.org">MDN Web Docs</a>

<!-- Relativo: arquivo na MESMA pasta -->
<a href="sobre.html">Sobre mim</a>

<!-- Relativo: arquivo dentro de uma subpasta -->
<a href="paginas/contato.html">Contato</a>

<!-- Relativo: subir UMA pasta (..) e entrar em outra -->
<a href="../index.html">Voltar ao início</a>

Imagine esta organização de pastas:

meu-site/
├── index.html
├── sobre.html
└── paginas/
    └── contato.html

Dentro do index.html, para ir ao contato você escreve paginas/contato.html (entra na pasta). Já dentro do contato.html, para voltar ao início você escreve ../index.html, onde os dois pontos .. significam "suba uma pasta".

⚠️
Erro número 1 dos iniciantes: link que "não abre"
Se o link dá erro 404, quase sempre o caminho está errado: letra maiúscula onde devia ser minúscula (Sobre.html ≠ sobre.html no servidor), espaço no nome do arquivo, ou pasta errada. Dica: use sempre letras minúsculas, sem espaços e sem acentos nos nomes de arquivos, trocando espaços por hífen (meu-curriculo.html).

🪟 Abrindo o link em uma nova aba

Por padrão, o link abre na mesma aba, substituindo a página atual. Para abrir em uma nova aba, usamos o atributo target="_blank":

📄 Link em nova aba 
<a href="https://www.wikipedia.org" target="_blank" rel="noopener noreferrer">Wikipédia (nova aba)</a>

Repare que adicionamos também rel="noopener noreferrer". Ele é uma medida de segurança: impede que a página aberta tenha algum controle sobre a sua página original. É uma boa prática sempre usar os dois juntos.

🎯
Quando usar nova aba?
Use para links externos (outros sites), assim a pessoa não perde o seu site. Para links internos (suas próprias páginas), o ideal é deixar abrir na mesma aba, já que a pessoa está navegando pelo seu site.

📍 Âncoras: links para dentro da mesma página

Em páginas longas (como este módulo!) é útil pular direto para uma seção. Para isso criamos uma âncora em dois passos:

Passo 1: dê um id único à seção de destino.
Passo 2: crie um link cujo href é # seguido do mesmo id.

📄 Link âncora 
<!-- Passo 2: o link (pode estar no topo da página) -->
<a href="#contato">Ir para o contato</a>

<!-- ...muito conteúdo no meio... -->

<!-- Passo 1: o destino, com o id -->
<h2 id="contato">Contato</h2>
<p>Fale comigo pelo email.</p>
⚠️
Atenção ao #
O id é escrito sem o # (id="contato"), mas o link usa com o # (href="#contato"). E cada id deve ser único na página: não repita o mesmo id em dois elementos.
💡
Truque útil: voltar ao topo
Um link <a href="#">Voltar ao topo</a> (só com o #) leva ao início da página. Muito usado em rodapés.

📧 Links para email e telefone

Links não servem só para páginas. Com os prefixos mailto: e tel: você abre o programa de email ou o discador do celular:

📄 Email e telefone 
<a href="mailto:contato@exemplo.com">Envie um email</a>

<a href="tel:+5511999999999">Ligue: (11) 99999-9999</a>
👁️ Resultado

Envie um email

Ligue: (11) 99999-9999

📱
Detalhe do telefone
No tel:, escreva o número sem espaços, parênteses ou traços, com o código do país (+55 para o Brasil). O texto visível pode ter a formatação que você quiser.

♿ Escrevendo bons textos de link

O texto do link precisa fazer sentido sozinho. Quem usa leitor de tela (pessoas cegas, por exemplo) costuma navegar ouvindo só a lista de links da página. Ouvir "clique aqui" dez vezes não ajuda ninguém. Compare:

📄 Ruim x Bom 
<!-- Ruim: não diz para onde vai -->
<p>Para ver o curso completo, <a href="curso.html">clique aqui</a>.</p>

<!-- Bom: o link descreve o destino -->
<p>Veja o <a href="curso.html">curso completo de HTML</a>.</p>

Você também pode usar o atributo title para uma dica que aparece ao passar o mouse, mas não dependa dele: celulares não têm "passar o mouse", então o texto do link continua sendo o mais importante.

🧭 Criando um menu de navegação com <nav>

Quando um grupo de links forma o menu principal do site, o correto é envolvê-los na tag <nav> (de navigation). Ela não muda a aparência, mas diz ao navegador e aos leitores de tela: "aqui está a navegação".

📄 Menu simples 
<nav>
  <a href="index.html">Início</a> |
  <a href="sobre.html">Sobre</a> |
  <a href="contato.html">Contato</a>
</nav>
👁️ Resultado
Início | Sobre | Contato
📚
Spoiler do futuro
Os menus de verdade costumam usar listas dentro do <nav>. Você vai aprender listas no módulo 6 e a tag <nav> com mais profundidade no módulo 9 (Semântica HTML5). Por enquanto, os links separados por | funcionam bem!

🎯 Exercício Prático

Monte um Mini Site de 3 Páginas

Hora de colocar os links em prática criando um site pequeno, com navegação entre as páginas. Clique nos quadrados para marcar cada passo concluído.

📋 Instruções:
💡 Ponto de partida: index.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Início - Meu Site</title>
</head>
<body>
  <nav>
    <a href="index.html">Início</a> |
    <a href="sobre.html">Sobre</a> |
    <a href="contato.html">Contato</a>
  </nav>

  <h1>Bem-vindo ao meu site</h1>
  <!-- Continue daqui: link externo, nova aba... -->
</body>
</html>
