Estrutura Básica

Toda página HTML segue uma estrutura padrão. Neste módulo, você vai aprender a anatomia de um documento HTML e o papel de cada elemento essencial.

🏗️ A Anatomia de uma Página HTML

Toda página HTML é como um sanduíche: tem camadas que se encaixam uma dentro da outra. A estrutura básica sempre segue este padrão:

📄 Estrutura base de todo documento HTML 
<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título da Página</title>
  </head>
  <body>
    <!-- O conteúdo visível fica aqui -->
  </body>
</html>

Vamos entender cada parte dessa estrutura:

📜 <!DOCTYPE html>

A primeira linha de todo documento HTML deve ser a declaração do tipo de documento. Ela diz ao navegador: "Ei, isso aqui é um documento HTML5!"

Sem essa linha, o navegador pode entrar em um modo de compatibilidade estranho e sua página pode não funcionar corretamente.

✅ Correto 
<!DOCTYPE html>
<html>
  ...
⚠️
Importante!
O <!DOCTYPE html> não é uma tag HTML — é uma declaração. Ele não tem tag de fechamento e deve ser sempre a primeira coisa no arquivo, antes mesmo da tag <html>.

🌐 A Tag <html>

A tag <html> é o elemento raiz de toda a página. É como a casca do ovo — tudo fica dentro dela. Todo o conteúdo HTML deve estar entre <html> e </html>.

O atributo lang (de language, idioma) é muito importante. Ele diz ao navegador qual é o idioma principal da página:

lang="pt-BR" ← Português do Brasil

Outros exemplos comuns:

ValorIdioma
pt-BRPortuguês (Brasil)
ptPortuguês (geral)
enInglês
en-USInglês (EUA)
esEspanhol
♿
Acessibilidade
O atributo lang ajuda leitores de tela (usados por pessoas com deficiência visual) a pronunciarem o conteúdo corretamente. Sempre inclua esse atributo!

🧠 A Tag <head> — O "Cérebro" da Página

A tag <head> contém informações sobre a página. O conteúdo do <head> não aparece na tela para o usuário, mas é essencial para o funcionamento correto da página.

Dentro do <head>, os elementos mais comuns são:

TagFunçãoObrigatório?
<title>Título da aba do navegador✅ Sim
<meta charset>Codificação de caracteres (UTF-8)✅ Sim
<meta viewport>Configuração para mobile✅ Sim
<meta name="description">Descrição para Google❌ Não
<link rel="stylesheet">Link para arquivo CSS❌ Não
<link rel="icon">Ícone da aba (favicon)❌ Não
📄 Exemplo completo do <head> 
<head>
  <!-- Codificação de caracteres -->
  <meta charset="UTF-8">

  <!-- Configuração para mobile -->
  <meta name="viewport" 
        content="width=device-width, initial-scale=1.0">

  <!-- Título da aba -->
  <title>Minha Página Incrível</title>

  <!-- Descrição para o Google -->
  <meta name="description" 
        content="Uma página sobre aprender HTML">

  <!-- Link para CSS externo -->
  <link rel="stylesheet" href="estilo.css">
</head>
💡
UTF-8 é essencial!
O charset="UTF-8" garante que caracteres especiais como ç, ã, é, emojis e símbolos sejam exibidos corretamente. Sempre inclua essa meta tag!

👁️ A Tag <body> — O Corpo Visível

A tag <body> é onde fica tudo que o usuário vê na tela: textos, imagens, links, botões, vídeos... Se está na tela, está no <body>.

Todo o conteúdo visível da página deve estar entre <body> e </body>.

📄 Conteúdo visível dentro do <body> 
<body>
  <h1>Bem-vindo!</h1>
  <p>Este é um parágrafo visível.</p>
  <img src="foto.jpg" alt="Minha foto">
</body>

💬 Comentários

Comentários são trechos de código que o navegador ignora. Eles servem para você deixar anotações, explicar o código ou temporariamente desativar uma parte do HTML.

💬 Exemplos de comentários 
<!-- Isso é um comentário de uma linha -->

<!--
  Isso é um comentário
  de várias linhas.
  Útil para explicações longas!
-->

<h1>Título visível</h1>
<!-- <p>Este parágrafo está comentado</p> -->
🎯
Boa prática
Use comentários para organizar seu código em seções. Por exemplo: <!-- HEADER -->, <!-- MAIN CONTENT -->, <!-- FOOTER -->. Isso ajuda muito na hora de encontrar coisas!

🗺️ Mapa Visual da Estrutura

<!DOCTYPE html> — Declara o tipo de documento
<html> — Elemento raiz (tudo fica aqui dentro)
<head> — Informações sobre a página (não visíveis)
<body> — Conteúdo visível da página
