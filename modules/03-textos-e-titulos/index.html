Textos e Títulos

Aprenda a criar títulos hierárquicos, parágrafos, quebras de linha e como dar ênfase ao texto usando as tags corretas.

📰 Títulos: <h1> a <h6>

O HTML oferece seis níveis de títulos, do <h1> (mais importante) ao <h6> (menos importante). Eles funcionam como a hierarquia de um livro: capítulo, seção, subseção...

Pense nos títulos como a estrutura de um documento:

👁️ Visualização dos títulos

Título H1 — Principal

Título H2 — Seção

Título H3 — Subseção

Título H4

Título H5
Título H6
📄 Código dos títulos 
<h1>Título Principal da Página</h1>
<h2>Capítulo 1</h2>
<h3>Seção 1.1</h3>
<h4>Subseção 1.1.1</h4>
<h5>Detalhe</h5>
<h6>Nota de rodapé</h6>
⚠️
Regra de ouro: um único <h1> por página!
Cada página deve ter apenas um <h1>. Ele representa o tema principal da página. Os demais títulos (h2 a h6) organizam o conteúdo em seções e subseções. Não pule níveis (não vá de h2 direto para h4)!
🔍
SEO e Acessibilidade
O Google usa os títulos para entender o conteúdo da sua página. Uma hierarquia bem organizada ajuda seu site a aparecer melhor nas buscas. Leitores de tela também usam os títulos para navegação — uma hierarquia correta é fundamental para acessibilidade.

📝 Parágrafos: <p>

A tag <p> é usada para criar parágrafos de texto. Cada parágrafo é automaticamente separado dos outros por um espaço em branco.

📄 Exemplo de parágrafos 
<p>Este é o primeiro parágrafo.</p>
<p>Este é o segundo parágrafo. Note que há um espaço entre eles.</p>
<p>Este é o terceiro parágrafo. Cada tag <p> cria um bloco separado.</p>
👁️ Resultado

Este é o primeiro parágrafo.

Este é o segundo parágrafo. Note que há um espaço entre eles.

Este é o terceiro parágrafo. Cada tag <p> cria um bloco separado.

↩️ Quebra de Linha: <br>

A tag <br> (de break, quebra) cria uma quebra de linha dentro de um texto. Diferente do <p> que cria um novo parágrafo, o <br> apenas pula uma linha.

⚠️ Atenção: <br> é uma tag auto-fechada — ela não tem tag de fechamento!

📄 Exemplo de quebra de linha 
<p>Rua das Flores, 123<br>
Bairro Centro<br>
São Paulo - SP<br>
CEP: 01000-000</p>
👁️ Resultado

Rua das Flores, 123
Bairro Centro
São Paulo - SP
CEP: 01000-000

⚠️
Não abuse do <br>!
Use <br> apenas para quebras de linha dentro de um mesmo contexto (como endereços ou poemas). Para separar conteúdos diferentes, use <p>. Nunca use vários <br> seguidos para criar espaço — isso é trabalho do CSS!

➖ Linha Horizontal: <hr>

A tag <hr> (de horizontal rule, régua horizontal) cria uma linha horizontal que separa seções de conteúdo. É uma tag auto-fechada, assim como o <br>.

📄 Exemplo de linha horizontal 
<h2>Introdução</h2>
<p>Texto da introdução...</p>

<hr>

<h2>Desenvolvimento</h2>
<p>Texto do desenvolvimento...</p>
👁️ Resultado

Introdução

Texto da introdução...

Desenvolvimento

Texto do desenvolvimento...

💪 Ênfase no Texto: <strong> e <em>

Para dar ênfase ao texto, usamos as tags <strong> (negrito, importância forte) e <em> (itálico, ênfase).

Essas tags são semânticas — elas não apenas mudam a aparência, mas também dizem ao navegador e aos leitores de tela que aquele trecho tem importância especial.

Tag Significado Aparência padrão Uso
<strong> Importância forte Negrito Alertas, avisos, palavras-chave
<em> Ênfase Itálico Destaque em frases, termos estrangeiros
📄 Exemplo de ênfase 
<p>O HTML é <strong>muito importante</strong> para a web.</p>

<p>A palavra <em>código</em> vem do latim <em>codex</em>.</p>

<p>Você <strong>deve</strong> sempre usar <em>tags semânticas</em>.</p>
👁️ Resultado

O HTML é muito importante para a web.

A palavra código vem do latim codex.

Você deve sempre usar tags semânticas.

💡
<b> e <i> vs <strong> e <em>
Existem também as tags <b> (bold) e <i> (italic), que apenas mudam a aparência sem significado semântico. Prefira sempre <strong> e <em> — elas são mais acessíveis e melhores para SEO.

📋 Resumo das Tags

Tag Função Tag de fechamento?
<h1> a <h6>Títulos hierárquicos✅ Sim
<p>Parágrafo✅ Sim
<br>Quebra de linha❌ Não (auto-fechada)
<hr>Linha horizontal❌ Não (auto-fechada)
<strong>Importância forte (negrito)✅ Sim
<em>Ênfase (itálico)✅ Sim
🎯 Exercício Prático

Crie uma Página Sobre Você

Use tudo o que aprendeu neste módulo para criar uma página pessoal simples.

📋 Instruções:
  • Crie um arquivo chamado sobre-mim.html
  • Use a estrutura completa do módulo anterior (<!DOCTYPE>, <html>, <head>, <body>)
  • Adicione um <h1> com seu nome
  • Adicione um <h2> "Sobre mim" e um parágrafo contando quem você é
  • Adicione um <h2> "Meus hobbies" e liste pelo menos 3 hobbies em parágrafos
  • Use <strong> para destacar palavras importantes
  • Use <em> para dar ênfase em algum trecho
  • Use <hr> para separar as seções
  • Adicione um <h2> "Contato" com seu email usando quebras de linha (<br>)
